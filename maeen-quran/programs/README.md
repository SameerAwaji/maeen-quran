# البرامج المشغّلة على المنصة

كل مجلد هنا = برنامج مستقل بنفس كود المنصة، لكن بقاعدة بيانات وهوية خاصة به.

```
programs/
  makanoon/
    config.js              ← إلزامي (يُنزَّل من «مسؤول المنصة ← خطوات التشغيل»)
    manifest.webmanifest   ← اختياري (اسم التطبيق ولونه عند تثبيته على الجوال)
    icon-192.png           ← اختياري (شعار البرنامج)
    icon-512.png           ← اختياري
```

- اسم المجلد = المعرّف بالإنجليزي، ويصير رابط البرنامج: `.../maeen-quran/<المعرّف>/`
- عند أي رفع على main يُبنى البرنامج الأساسي وكل البرامج هنا تلقائياً بآخر نسخة من الكود.
- لا تضع أبداً مفتاح `service_role` في أي ملف هنا.
